# Pet_ID
Gerador de qr-codes para identificação de pets

Para usar instale as dependencias e bibliotecas:
pip install pillow
pip install qrcode
pip install qrcode[pil]
pip install flask

para rodar execute o arquivo app.py
No terminal uma URL como: HTTP://127.0.0.1:5000 ira ser gerada.
Copie e cole no navegador para abrir a pagina de cadastro.
Ao concluir, o qr-code sera exibido e você podera visualizar a pagina com a carteirinha de identificação do pet.
